# Dane
Dane **nie są** częścią repozytorium (licencja CC BY-NC-SA 4.0 i rozmiar).

## Jak pobrać
1. Wejdź na: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
2. Pobierz zbiór (wymaga darmowego konta Kaggle).
3. Rozpakuj 9 plików CSV do folderu poza repozytorium, np. `C:\data\olist\`.
4. Zaimportuj do SQL Server zgodnie z `sql/00_create_database.sql` i opisem w
README.
